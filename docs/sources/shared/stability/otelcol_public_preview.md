> **Public preview**: This is a [public preview][] component.
> Its stability is tied to the stability of the upstream OpenTelemetry Collector component it wraps.
> Public preview components can have breaking changes between releases, including breaking changes from upstream.
> To enable and use a public preview component, you must set the `stability.level` [flag][] to `public-preview` or below.
> Setting the flag can also enable public preview behavior in functionality that's otherwise generally available.
