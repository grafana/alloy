> **EXPERIMENTAL**: This is an [experimental][] component.
> Its stability is tied to the stability of the upstream OpenTelemetry Collector component it wraps.
> Experimental components can have breaking changes between releases, including breaking changes from upstream.
> To enable and use an experimental component, you must set the `stability.level` [flag][] to `experimental`.
> Setting the flag can also enable experimental behavior in functionality that's otherwise generally available.
